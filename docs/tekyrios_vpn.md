# Guía de Conexión VPN — Tekyrios SAS

## Síntomas comunes
- No se puede establecer túnel VPN
- Conexión se cae cada pocos minutos
- Error de autenticación en el cliente VPN

## Solución paso a paso
1. Verificar credenciales en el portal de acceso
2. Comprobar que el certificado no ha expirado
3. Reiniciar el servicio de cliente VPN
4. Si persiste, crear ticket de soporte técnico

## Requisitos de red
- Puerto UDP 1194 abierto en firewall
- DNS interno: 10.0.0.53
